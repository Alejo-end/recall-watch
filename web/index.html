How the loop works

What a page state means

A page state is what the page visibly said when Context.dev read it. “Appears purchasable” means normal purchase words were on the page. It does not prove that a recalled lot was in stock or sold. The exact moment a page changed is unknown: each lag is an upper bound, with the window in which the change happened. The Finnish notice is authoritative; the English title is a working translation. Names in the audit trail are typed by the operator: this pilot has no user accounts, so they are attribution, not proof of identity.
